# 夏夜将终：一个乐队官网是怎么搭的

2023 年夏天快结束的一个晚上，几个人因为夜鹿（ヨルシカ / Yorushika）走到了一起，组了一支校园乐队，名字叫「夏夜将终」。

后来，他们给自己做了一个官网，而且是照着 Yorushika 官网的样子做的。

## 这个网站长什么样

一句话：**一支乐队的官网，复刻自 Yorushika 的官网模板。**

- 深紫配色，主色 `#3D2B5F`，走夜鹿官网的气质；
- 有乐队简介、成员、演出、翻唱作品、歌词、新闻这些页面；
- 成员挺全：Vocal、Guitar、Bass、Drums、Violin、Keyboard，还有一个「Salute to 沼跃鱼」。

乐队目前在 B 站叫 **夏夜将终_Official**。

## 网站怎么维护

这个网站最聪明的地方是：**不用改网页代码，改 Markdown 就行。**

所有内容（简介、作品、演出、歌词……）都放在 `content/` 文件夹里的 `.md` 文件里：

```text
content/
├── band.md      # 乐队简介、成员
├── works.md     # 翻唱作品
├── shows.md     # 演出
├── site.md      # 站点名、配色、B站账号
└── lyrics/      # 歌词，一首一个文件
```

改完推送，GitHub 的自动化流程会自动把 Markdown 编译成网站数据，然后直接上线。想更新内容，只需要会写 Markdown 就行。

## 一个小总结

这个项目很可爱的一点是：它不是为了炫技，而是**一群喜欢同一支乐队的人，想给自己的乐队做一个同样好看的家**。

技术上也够简单直接——内容与展示分离、自动化构建、免费部署，一套下来一个人也能维护。

> 所以夏夜其实还不会结束——
